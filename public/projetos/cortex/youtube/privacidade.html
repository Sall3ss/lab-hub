Política de Privacidade

Esta política explica como o Cortex usa os dados da conta Google quando o dono do canal conecta o YouTube.

Dados acessados

  • youtube.upload: enviar ao canal os Shorts que o dono aprovou no Cortex.
  • youtube.readonly: ler o nome e o ID do canal conectado, para mostrar ao dono onde os vídeos serão publicados.

O Cortex não lê e-mail, contatos, comentários, estatísticas nem qualquer outro dado da conta.

Onde os dados ficam

  • A autorização do Google (token) fica só no computador do dono, protegida pela criptografia do Windows do usuário. Ela nunca é enviada ao servidor do Cortex.
  • Os vídeos saem do computador do dono direto para o YouTube.
  • O servidor do Cortex guarda apenas o nome do canal, o ID de cada vídeo enviado, a privacidade escolhida e o título e a descrição usados. Esses dados servem para mostrar o andamento e evitar o envio do mesmo vídeo duas vezes.

Compartilhamento

Nenhum dado é vendido, compartilhado com terceiros ou usado para publicidade. Os dados também não são usados para treinar modelos de inteligência artificial.

O uso e a transferência de informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

Como revogar e apagar

  • O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions, ou no próprio computador, com o comando node cortex-agente.mjs youtube-sair, que apaga o token local.
  • Os registros de envio guardados no Cortex podem ser apagados pelo dono no painel.

O uso do YouTube também está sujeito aos Termos de Serviço do YouTube e à Política de Privacidade do Google.
